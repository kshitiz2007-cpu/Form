# QuizFlow Telegram Bot

## Setup
1. Install Node.js 20+.
2. In this folder, run `npm install`.
3. Copy `.env.example` to `.env` and set `TELEGRAM_BOT_TOKEN`.
4. Run `npm start`.

Commands: `/start`, `/quiz`, `/leaderboard`.

**Never commit .env or paste the bot token into frontend code.** The token shared in chat should be revoked in BotFather and replaced with a fresh token.
